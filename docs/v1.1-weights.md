## 摘要

分层记忆系统以「重要度定层级、时间定衰减」压缩上下文。召回阶段如何融合**相关性**与**时效性**，
决定系统在两类查询上的表现：历史性提问（「当初为什么这么定」）要求陈旧但相关的证据优先；
状态性提问（「现在是什么」）要求新鲜证据优先。已有工作普遍采用加性线性组合
（`q = w₁·rel + w₂·recency + w₃·imp`）[1]。

本文首先证明：**在该形式下，不存在能同时召回正例与排除负例的阈值**（定理 5）。
缺陷是形式性的，无法通过调参消除。据此提出**有界乘性修正**：

```
q = r · ( f + (1 − f) · δ )
```

其中 `r` 为相关性分，`δ ∈ (0,1]` 为衰减因子，`f ∈ [0,1]` 为时间下限。
定理 3 给出两候选次序可被时效性反转的充要条件 `r_A/r_B < m_B/m_A`；
推论 1 给出其上确界 `1/f`——**时效性只能在相关性差距不超过 `1/f` 倍时改变次序**。

在 11 条开发用例与 10 条留出用例上，本报告将 `f` 取为 `0.62`：开发集与留出集成对一致率均为
`1.000`，而原默认值 `0.70` 为 `0.818 / 0.800`。消融实验显示，按查询意图切换 `f` **不带来增量**
（开发集 `0.909`，低于固定值的 `1.000`），且引入一个召回率仅 `0.500` 的分类组件。

最后给出四条方法学教训，其中最反直觉的一条是：**当留出集的可行区间比开发集宽 `7.6` 倍时，
它只能否证极端取值，不能确认精确取值**——此时「留出集验证了某值」是一句错话。

**关键词**：记忆召回；时间衰减；分数融合；阈值可分离性；负结果

## 1 引言

### 1.1 问题

长上下文系统需要在有限预算内从海量历史中挑出少量片段。分层记忆（T0–T9）用两条独立机制做初筛：
**重要度定层级**（层级决定召回策略与保留期限），**时间定衰减**（半衰期决定旧得多快）。
初筛之后，剩余候选需要一个标量分数来排序。该分数的构造方式直接决定两类查询能否同时被满足：

- **历史性提问**（Q_hist）：「当初为什么放弃自建存储？」——标准答案是陈旧但高度相关的记录；
- **状态性提问**（Q_stat）：「目前线上跑的是哪个版本？」——标准答案是最新的记录，即使其字面相似度更低。

二者的要求方向相反。若把时效性作为与相关性并列的加权项，则这两类查询对权重的需求互斥。

### 1.2 本文工作

1. **形式化一个加性方案的可分离性缺陷**（定理 5）：存在正负例对，使负例分数高于正例，
   故任何阈值都无法分离。这一点在 v1.0 设计中被观察到但未被证明。
2. **提出有界乘性修正**，并证明其可反转条件与上确界（定理 3、推论 1、推论 2）。
   该形式保证时效性**不能**反转差距较大的相关性。
3. **给出可复现的评测协议**：开发集与留出集物理隔离；指标为成对一致率、**floor 落带率**
   与阈值可分离性；全部实验由脚本产出（`tools/run_rank_eval.py`、`tools/run_holdout.py`）。
4. **否定三个自设假设**，并给出四条可迁移的方法学教训（§7.3）。其中「按查询意图调节时间下限」
   是本报告最初主张、后被自身实验否定的方案。

### 1.3 结论摘要

在 21 条人工标注用例上，一个**固定常数** `f = 0.62` 即达到开发集与留出集双满分；
所有依赖上下文信号的变体（按意图硬切换、连续敏感度插值、名次融合）均未超过它。
因此本报告的最终建议是**降低一个常数，而非增加一层机制**。

## 2 相关工作

**分层记忆与上下文压缩** 以层级与保留期限管理长期状态的做法见于 MemGPT [2]，
其以分页方式在有限上下文窗口内调度历史。本报告关注层级既定之后**召回排序**的融合形式。

**加性融合** 生成式智能体 [1] 的检索分数为三项加权和：时效性（按小时指数衰减）、
重要性（模型打分）、相关性（嵌入余弦）。该形式与本报告证明不可分离的加性方案同构（定理 5），
其实现按等权归一后求和。

**名次融合** 倒排名次融合（RRF）[3] 通过融合名次而非分数来规避不同信号量纲不可比的问题，
在混合检索（稀疏 BM25 [4] + 稠密向量 [7]）中是标准做法。本报告将其作为对照方案之一（§6.2），
并报告它在本文用例集上劣于有界乘性修正。

**时间衰减模型** 遗忘曲线 [5] 与记忆强度的幂律衰减 [6] 说明「随时间衰减」的建模存在多种函数形式。
本报告采用半衰期形式 `δ = 0.5^(Δ/h)` 而非时间常数形式 `exp(−Δ/τ)`；
后者在 `Δ = h` 时给出 `0.368` 而非 `0.5`，即标注的「半衰期」实际只相当于 `0.693` 倍标注值。
本报告在 v1.0 修订中修正了这一处语义偏差。

**说明** 本报告未重新实现任何外部系统；上述文献用于界定问题与对照方案的位置。

## 3 问题形式化

### 3.1 记号

| 符号 | 含义 | 取值域 |
|---|---|---|
| `s` | 语义相似度（余弦） | `[-1, 1]` |
| `σ` | 归一化相似度 `(1+s)/2` | `[0, 1]` |
| `i` | 卡的重要度（整数） | `{1, …, 10}` |
| `μ` | 实体 / 任务匹配度 | `[0, 1]` |
| `r` | 相关性分 | `[0.027, 1]` |
| `Δ` | 卡龄（天） | `[0, ∞)` |
| `h` | 半衰期（天）；`h = 0` 表示不衰减 | `[0, ∞)` |
| `δ` | 衰减因子 | `(0, 1]` |
| `f` | 时间下限 | `[0, 1]` |
| `m` | 时间修正系数 | `(f, 1]`（`h > 0`）；`{1}`（`h = 0`） |
| `q` | 最终分数 | `(0.027 f, 1]` |
| `θ, θ′` | 硬门阈值（T2–T5 / T6–T7） | `[0, 1]` |

### 3.2 定义

**定义 1（相关性）** `r = w_σ σ + w_i (i/10) + w_μ μ`，`w_σ + w_i + w_μ = 1`。

**定义 2（衰减因子）** `δ(Δ,h) = 1`（`h = 0`）；`δ(Δ,h) = 0.5^(Δ/h)`（`h > 0`）。

**定义 3（有界乘性修正）** `m(Δ,h; f) = f + (1 − f) δ(Δ,h)`，`q = r · m`。

**定义 4（加性融合，对照）** `a = 0.45 σ + 0.25 δ + 0.20 (i/10) + 0.10 μ`（v1.0 形式）。

**定义 5（硬门）** 候选进入上下文当且仅当按层级满足：

| 层级 | 条件 |
|---|---|
| T0, T1 | 恒成立 |
| T2, T3 | `q > θ` 或存在未完成待办 |
| T4, T5 | `Δ ≤ 30` 且 `q > θ` |
| T6, T7 | `Δ ≤ 7` 且 `q > θ′` |
| T8, T9 | 存在显式回溯请求 |

### 3.3 常量取值

| 常量 | 取值 | 来源 |
|---|---|---|
| `(w_σ, w_i, w_μ)` | `(0.60, 0.27, 0.13)` | v1.0 权重去掉衰减项后按 `0.75` 重新归一化（§6.8）；可行但贴近边界 |
| `f` | `0.62` | 实验标定（§6.3） |
| `θ, θ′` | `0.35, 0.55` | v1.0 继承（标定值 `0.3976, 0.36615`，尚未落地） |
| `h`（T0–T9） | `0, 365, 180, 90, 30, 14, 7, 3, 1, 1/24` | v1.0 继承（未约束） |

## 4 方法

### 4.1 相关性主轴

相关性由三项构成，权重和为 1，故 `r` 落在 `[0.027, 1]`（定理 1）。
权重分配的依据是「对不对题」优先于「重不重要」，后者优先于「是否命中实体」；
该分配未经实验约束，见 §7.2。

### 4.2 有界乘性修正

**定理 1（值域）** `σ ∈ [0,1]`、`r ∈ [0.027, 1]`、`m ∈ (f, 1]`（`h > 0`）、`q ∈ (0.027f, 1]`。

**定理 2（单调性）** `q` 对 `σ, i, μ` 严格递增；`h > 0` 且 `r > 0` 时对 `Δ` 严格递减；
`Δ > 0` 时对 `h` 严格递增。

定理 2 的形式化含义是：**时间只向下修正分数，且修正幅度有上界**。

**定理 3（可反转判定）** 设两条候选 A、B，`r_A, r_B > 0`，则

```
q_B > q_A   ⟺   r_A / r_B  <  m_B / m_A
```

**推论 1（反转上确界）** 若 `r_A / r_B ≥ 1/f`，则时效性无法反转次序；
且 `sup (m_B/m_A) = 1/f`。取 `f = 0.62`：`1/f = 50/31 = 1.612903…`。

**推论 2（不可达）** `1/f` 是上确界而非最大值：取等需 `Δ_A = ∞`。

命题 1–4 与推论 1–2 的证明见附录 A.2。定理 3 的直观含义：
**时效性只能在相关性差距不超过 `1/f` 倍时改变候选次序**，这一上界与具体卡龄无关。

### 4.3 加性形式不可分离

**定理 5** 对定义 4 的加性形式 `a`，存在正例 P 与负例 N 使 `a_N > a_P`；
因此不存在任何阈值 `θ` 能同时满足「召回 P」与「排除 N」。

*证明（反例，完整算式见附录 A.3）*：取 `N = (T3, i=2, Δ=10, s=0.15, μ=0)`，
`P = (T5, i=3, Δ=30, s=0.72, μ=0)`，则 `a_N = 0.530219 > 0.503608 = a_P`。
召回 P 要求 `θ < 0.503608`，排除 N 要求 `θ > 0.530219`，两式互斥。
两条候选都满足自身层级的卡龄窗口（T3 无窗口；T5 的 `Δ=30` 恰在 30 天上界内），
且分属不同用例——`θ` 是全局阈值，跨用例的反例比同用例更强。∎

定理 5 说明：**加性形式的缺陷不是参数选择不当，而是形式本身不可分离**。
这是必须更换融合形式、而非调整权重的依据。

## 5 实验设置

### 5.1 用例集

每个用例包含一次查询、一批候选（含层级、重要度、卡龄、相似度、实体命中），
以及**人工标注的期望次序**。两个集合物理隔离：

| 集合 | 条数 | 用途 | 标签 |
|---|---|---|---|
| 开发集 `eval/rank/` | 11 | 提出假设、扫描参数 | `intent` |
| 留出集 `eval/holdout/` | 10 | 检验假设 | `needs_fresh` |

留出集在运行前完成编写，其期望次序由一条**事前确定的原则**推导，与 `f` 的取值无关：
相关性差距大 → 相关性优先；差距中等 → 较新者优先；相关性相同 → 较新者优先。

留出集采用 `needs_fresh`（答案是否依赖最新状态）作为真值标签，而非 `intent`
（状态 / 任务 / 历史）。原因是后者的边界不可判定：查询「张三的报价给到了吗」在
「任务跟进」与「当前状态」之间没有客观归属，而「是否依赖最新状态」有。

### 5.2 指标

1. **成对一致率**：期望次序的全部候选对中，产出次序与其一致的比例。
2. **Floor 落带率**：某策略选出的 `f` 落在该用例可行区间内的比例。
   该指标替代了「时效性二分类准确率」——后者对本任务缺乏因果性（§6.5）。
3. **阈值可分离性**：给定正负例分数集，是否存在阈值区间 `(max a_N, min a_P)`。
4. **可行性区间**：使全部用例正确排序的 `f` 的集合，以步长 `0.002` 扫描得到。

### 5.3 协议

全部方案调用同一份打分代码（`score_card` 的 `scheme` 参数），不使用平行实现。
`f` 由开发集扫描得到，随后在留出集上检验；两集合的可行区间分别计算并求交（§6.4）。

### 5.4 系统另有的独立关卡

抽取环节另有一条精度关卡（`tools/run_eval.py`）：关键字段保留率 `1.000`、压缩率 `0.35×`。
该关卡与本文的排序实验相互独立，不构成本报告结论的一部分。

## 6 结果与分析

### 6.1 假设否证：加性形式在排序上并不更差

最初假设「加性形式会因时效项压制相关性而排序更差」。实验否定了这一假设：

| 方案 | n=6 一致率 | n=11 一致率 |
|---|---|---|
| 加性（0.45/0.25/0.20/0.10） | **0.933** | **0.970** |
| 有界乘性（`f = 0.70`） | 0.800 | 0.818 |
| 仅相关性 + 时间破同分 | 0.600 | 0.636 |
| 名次融合 RRF | 0.833 | 0.727 |
| 两分数 50/50 平均 | 0.833 | 0.909 |

加性形式在**排序一致率上更高**。它的缺陷只在**阈值可分离性**上暴露（定理 5、§6.6），
以及「任务跟进」类用例上（§6.2 按意图拆分）。

**教训**：融合形式的好坏必须用**多个指标**衡量。仅看排序一致率，会得出与事实相反的结论。

### 6.2 消融一：上下文信号（按意图切换 `f`）

| 方案 | 融合算术 | 上下文来源 | 开发集 | 留出集 |
|---|---|---|---|---|
| 有界乘性（固定 `f`） | 乘性 | 无 | **1.000** | **1.000** |
| + 按意图硬切换 `f` | 乘性 | 措辞推断 | 0.909 | 1.000 |
| + 按意图硬切换 `f` | 乘性 | oracle 意图 | 1.000 | — |
| + 连续敏感度插值 | 乘性 | 措辞推断 | 1.000 | 1.000 |
| RRF 名次融合 | RRF | 措辞推断 | 0.727 | — |
| 两分数 50/50 平均 | 分数平均 | 措辞推断 | 0.970 | — |

（`f = 0.62` 下测得。50/50 平均的下降说明：**把加性形式混入会一并混入其结构性缺陷**。）

按查询意图拆分（`f = 0.62`）：

| 查询意图 | 加性 | 乘性（固定） | 仅相关性 | RRF | 50/50 |
|---|---|---|---|---|---|
| 历史决策 | 1.000 | 1.000 | 1.000 | 0.500 | 1.000 |
| 长期偏好 | 1.000 | 1.000 | 1.000 | 1.000 | 1.000 |
| 当前状态 | 1.000 | 1.000 | 0.000 | 0.500 | 1.000 |
| 任务跟进 | 0.917 | 1.000 | 1.000 | 1.000 | 0.917 |

**结论**：在正确的固定下限下，**上下文信号不带来任何增量**；按意图切换反而更差
（开发集 `0.909 < 1.000`）。这是本报告最初主张的方案，被自身实验否定。

### 6.3 消融二：`f` 的扫描

以步长 `0.002` 扫描 `f ∈ [0,1]`，算术固定为有界乘性修正：

| 集合 | 全通过窗口 | 宽度 | 中点 |
|---|---|---|---|
| 开发集（11 条） | `[0.608, 0.634]` | `0.026` | `0.621` |
| 留出集（10 条） | `[0.466, 0.664]` | `0.198` | `0.565` |
| **交集** | `[0.608, 0.634]` | `0.026` | **`0.621`** |

采纳值 `f = 0.620`（扫描网格点），到中点距离 `0.001`，到下界余量 `+0.012`，到上界余量 `+0.014`。
选值判据为**最小最大余量**：在「哪条用例代表现实」未知时，使最坏情况下到最近约束的距离最大。

窗口宽度的来源是**少数用例**：开发集侧由 `03-task-continuation` 定下界、
`05-status-stale-strong` 与 `06-status-without-markers` 定上界；留出集侧由 `H04` 与 `H02` 定界。
**21 条用例中只有 5 条决定该区间的宽度。**

### 6.4 留出检验：能确认的只有「`0.70` 过高」

| 策略 | 开发集 | 留出集 |
|---|---|---|
| `f = 0.70`（原默认） | 0.818 | 0.800 |
| `f = 0.62`（采纳） | 1.000 | 1.000 |
| `f = 0.55` | 0.970 | 1.000 |
| `f = 0.50` | 0.939 | 1.000 |
| `f = 0.35` | 0.818 | 0.900 |

留出集的可行区间（`0.198` 宽）**完整包含**开发集区间且宽 `7.6` 倍。其直接推论是：
**`f = 0.55`、`0.60`、`0.63`、`0.64` 在留出集上同样全对**，留出集只排除
`f < 0.466` 与 `f > 0.664`——它否证了 `0.70`，但没有分辨力**确认** `0.62`。

因此 `0.62` 的地位是：**交集的最小最大余量点**，而非被独立验证的真值。
本报告此前曾表述为「留出集验证了 `0.62`」，该表述是错误的，此处更正。

### 6.5 消融三：意图识别指标本身

把时效性识别当作二分类任务度量，得到偏悲观的图景：

| 集合 | 准确率 | 召回（需时效性类） | 精确率 |
|---|---|---|---|
| 开发集 | 0.727 | 0.500 | 0.667 |
| 留出集 | 0.700 | 0.500 | 1.000 |

但改用 **floor 落带率** 后：`f = 0.70` 时错放 `1/11`（仅第 06 号用例）；
`f = 0.62` 时错放 `0/11`。留出集上的三个漏判（`H02`、`H03`、`H07`）**全部落在各自可行区间内**，
未造成任何排序错误。

**结论**：二分类准确率对本任务缺乏因果性。决定成败的是参数落点，而非标签是否判对。
一个中间指标若其错误不必然导致目标失败，则不适合作为优化目标。

### 6.6 阈值标定

| 方案 | 分组 | 负例上界 | 正例下界 | 区间宽度 | 建议值 |
|---|---|---|---|---|---|
| 加性 | `θ` | `0.5302` | `0.5036` | **不可行** | — |
| 加性 | `θ′` | `0.4726` | `0.5263` | `0.0537` | `0.4995` |
| 有界乘性（固定 `f=0.62`） | `θ` | `0.3878` | `0.4215` | `0.0337` | `0.4046` |
| 有界乘性（固定 `f=0.62`） | `θ′` | `0.3326` | `0.3997` | `0.0671` | `0.3662` |
| 有界乘性（连续插值下限） | `θ` | `0.3878` | `0.4022` | `0.0144` | `0.3950` |
| 有界乘性（连续插值下限） | `θ′` | `0.3326` | `0.3997` | `0.0671` | `0.3662` |

现行值 `0.35` / `0.55` 均落在区间之外，切换前必须替换。

**不可行的来源**（`09` 的 `weak-t3` 负例 `0.530219` 对 `17` 的 `paraphrase` 正例 `0.503608`，
两条都窗口合法）见附录 A.3。用超窗卡当正例会**高估**不可行程度：`0.4932` 这个旧下界
来自一张超出 T5 窗口的 `Δ=120` 候选，它本就不该进入候选集。

附带观察：固定下限一族里，`f` 由 `0.70` 降至 `0.62` 时，`θ` 的可行区间由宽 `0.0684`
收窄至 `0.0337`（`f=0.70` 时区间为 `(0.3901, 0.4585)`）。
**放宽时效性话语权与收窄阈值余地是同一笔取舍的两面**，两类参数并不独立。

### 6.7 稳健性：参数漂移下的反转区域

21 条用例只覆盖参数空间的一小块。真实分布到来时，**卡龄分布、相似度量级、重要度分布**都会漂移。
因此直接在参数网格上测量两个方案的反转区域（`moonshadow.drift`，`tools/run_drift_check.py`）：
正例取无卡龄窗口的 T2/T3，卡龄 `5–800` 天、相似度 `0.70/0.85`；
负例为低相似度、无实体命中、`0.1–15` 天、重要度 `1/2`。共 `2304` 组配对。

| 方案 | 反转组数 | 占比 | 反转对里的最大 `r_P/r_N` | 越过 `1/f` 的反转 |
|---|---|---|---|---|
| 加性 | 173 | 7.51% | **1.8844** | **142** |
| 有界乘性 | 4 | 0.17% | 1.5845 | **0** |

**结构原因**：加性方案的分数含有一项 `0.25 δ`，它在相关性分 `r` 中没有对应项。
因此其反转条件里存在一个**与查询、与相关性都无关的年龄偏移**，年龄差可以独立推动反转。
乘性方案的反转条件（定理 3）是纯比值条件，且被 `1/f` 封顶（推论 1）。

**对漂移的回答**：若漂移主要改变**相似度量级**（例如更换嵌入模型），两方案同步受影响；
若漂移改变**卡龄分布**（真实语料必然如此），则只有加性方案的反转会增长，
且增长**不受任何相关性比值上界约束**——乘性方案那 `0.17%` 在任何卡龄分布下都不会越过 `1/f`。

须区分两件事：`f = 0.62` 这个**取值**是在特定卡龄画像下调出的，漂移会使其不再最优；
而**上界 `1/f` 的存在性**与数据无关，漂移不能使该保证失效。

### 6.8 相关性权重的敏感性：区域很大，但当前值停在边缘

`(w_σ, w_i, w_μ)` 的来源是**算术推导，而非判断**。v1.0 的加性权重为 `(0.45, 0.25, 0.20, 0.10)`；
把 `decay` 移入乘性修正后，其余三项按 `0.75` 重新归一化：

```
0.45 / 0.75 = 0.600（精确）     0.20 / 0.75 = 0.2667 → 0.27     0.10 / 0.75 = 0.1333 → 0.13
```

因此这三个数不携带任何独立依据。为判断其影响，在权重单纯形上扫描 `f = 0.62` 下的成对一致率
（`sweep_weights`，步长 `0.01`，`5151` 个点）：

| 集合 | 可行点 | 占比 | 可行区域重心 |
|---|---|---|---|
| 开发集 | 2006 / 5151 | 38.9% | `(0.344, 0.163, 0.493)` |
| 留出集 | 3273 / 5151 | 63.5% | `(0.387, 0.193, 0.419)` |

当前权重在两集合上一致率均为 `1.000`，**但位置很差**：

| 指标 | 值 |
|---|---|
| 当前点到最近不可行点的距离 | `0.0224`（约 `2` 个网格步） |
| 最近的不可行点 | `(0.61, 0.29, 0.10)`，一致率 `0.970` |
| 单独上调 `w_i` 约 | `+0.05` 即出界 |
| 单独上调 `w_σ` 约 | `+0.15` 即出界 |
| 最稳点（到边界距离最大） | `(0.37, 0.18, 0.45)`，距离 `0.1552` |
| 可行区域内 `w_i` 的跨度 | `[0.01, 0.34]`，当前 `0.27` 贴近上界 |

**结论**：可行区域占单纯形的 `38.9%`，所以「权重分配无关紧要」在本用例集上成立；
但当前值停在可行区的**角落**——`w_i` 贴近上界、`w_σ` 高于重心 `0.344`，到边界仅 `2` 步。
**区域大不等于取值稳**：当前权重属于「能过，但站不住」，其到边界的余量比最稳点小 `6.9` 倍。

这与 `f` 的情形形成对照：`f = 0.62` 位于自身可行区间的**中点**（minimax），
而权重位于自身可行区域的**边缘**。两者都是「未被独立数据约束」的参数，
但只有前者处在稳健位置上。

## 7 讨论

### 7.1 主要发现

1. **加性融合的缺陷是形式性的。** 定理 5 给出反例证明；其排序一致率反而更高（§6.1），
   因此该缺陷只能通过阈值可分离性发现。
2. **一个有界常数足以替代一层上下文机制。** 上下文信号的三种变体均未超过固定 `f = 0.62`（§6.2）。
3. **可反转上界是最准确的表述方式。** `f` 由 `0.70` 改为 `0.62`，等价于把可反转区间
   从 `(1, 1.428571)` 放宽到 `(1, 1.612903)`（推论 1）。
4. **少数用例决定参数。** 21 条用例中 5 条决定区间宽度，故 `0.62` 的精度不可当真；
   诚实表述为「落在 `0.61–0.63` 之间」。

### 7.2 威胁有效性

**内部有效性。** 全部 21 条用例由人工编写，期望次序由人工标注。
留出集与开发集共享同一套数值设定（层级、卡龄、相似度量级），因此 §6.4 检验的是
**同一设计假设下的参数泛化**，而非真实查询分布上的泛化。
`(w_σ, w_i, w_μ)` 的三项分配、十个半衰期、两个卡龄窗口在整个研究过程中固定，
**未受任何实验约束**——它们是占位值，全部结论在此占位值下测得。
§6.8 进一步显示：权重项虽然落在可行区域内，但到边界仅约 `0.022`（`2` 个网格步），
属于「能过但站不住」；这与 `f`（位于可行区间中点）是两类不同的风险。
十个半衰期与两个卡龄窗口连这样一次扫描都还没做过。

**构造有效性。** 成对一致率对候选数敏感：候选少时单次错位影响更大。
阈值标定所用的分数型负例仅 `3` 条（`θ`）与 `2` 条（`θ′`），区间约束较弱。

**外部有效性。** 用例数量（21）不足以支撑统计推断。§6.4 已经证明：把用例从 6 条扩到 11 条
即足以推翻基于 6 条的结论。真实查询分布数据是本结论外推的必要条件。

**用例集与硬门规则的一致性（本次审计发现的缺陷）。**
用例文件把 `candidates` 声明为「应被召回的候选」，但按定义 6，T4–T5 需 `Δ ≤ 30`、T6–T7 需 `Δ ≤ 7`。
审计（`tools/run_case_audit.py`）发现 **9 张正例候选超出其层级窗口**：
开发集 `03`/`04`/`05`/`06`/`08`/`09` 各一张，留出集 `H02`/`H03`/`H05` 各一张。
含义是：这些候选在真实流水线中会被卡龄窗口挡掉，相应用例的排序期望不会被执行。
本报告**未就地修正**这些用例——修正会改变全部已报告的数值（包括 `f` 的可行窗口）。
该缺陷记为已知问题，修正后须整体重跑 §6.2–§6.4。

**方法论风险。** 部分方案（连续敏感度插值、RRF、50/50 平均）是在观察到前几组结果后加入的，
存在对当前用例集过拟合的风险。`f = 0.62` 是在开发集上扫描得到的调参值，
与人工判断值之间不构成公平比较；留出集的作用是限制这种偏差，但受 §7.2 内部有效性所限。

### 7.3 方法学教训

1. **量纲不同源的信号不应放入同一加法式。** 强行定义「相关性—时效性」汇率，
   必然在某一类查询上失效（定理 5）。
2. **小样本上的「无差异」不等于「无差异」。** 6 条用例下三种融合算术完全一致，
   扩至 11 条后其中一种下降 `0.106`。应先扩样本再下结论。
3. **失败的性质比失败的次数更重要。** 结构性失败（补信息无法修复）与信息性失败（可修复）
   在聚合指标上可能相同，但决策方向相反。
4. **区分「机制不足」与「参数不当」。** 本报告最昂贵的一次误判是把「默认下限偏高」
   误诊为「缺少上下文信息」，为此实现了一整层意图切换机制，而该机制经消融后被否定（§6.2）。
5. **中间指标须与目标存在因果关系。** 二分类准确率的错误可能全部无害（§6.5）。
6. **留出集比开发集宽时，它不构成独立约束。** 应先分别计算两集合的可行区间，
   再判断留出集是否具有分辨力（§6.4）。

---

## 8 结论

召回排序中，**相关性应当是主轴，时效性应当是门、有界修正与冲突裁决，而不是与相关性并列的权重**。
本文证明了加性形式在阈值可分离性上的形式性缺陷（定理 5），
给出有界乘性修正的可反转条件与上确界（定理 3、推论 1），
并在开发集与留出集上确定了时间下限 `f = 0.62`。

消融实验表明，按查询意图调节该下限**不带来增量**，因此最终建议是
**降低一个常数，而非增加一层机制**。这一结论的适用范围受 §7.2 所列威胁限制：
全部证据来自 21 条人工用例。真实查询分布上的重估规则为：
固定其余常量，扫描 `f`，记录全通过区间，并与留出区间求交。

### A.2 定理 1–4 与推论 1–2 的证明

**定理 1（值域）**
(i) 由定义 `σ = (1+s)/2`：`s ≥ −1 ⇒ σ ≥ 0`；`s ≤ 1 ⇒ σ ≤ 1`。
(ii) 由 `i ∈ {1,…,10}` 得 `i/10 ∈ [0.1, 1]`，又 `μ ≥ 0`，故 `r ≥ w_i · 0.1 = 0.027`；
由 `w_σ + w_i + w_μ = 1` 且三项各自 `≤ 1`，得 `r ≤ 1`。
(iii) `h > 0` 时 `Δ/h ≥ 0`，故 `δ = 0.5^(Δ/h) ∈ (0, 1]`：`δ > 0` 给出 `m > f`；
`Δ = 0 ⇒ δ = 1 ⇒ m = 1`。`h = 0` 时 `m = f + (1−f) = 1`。
(iv) `q = r m`，由 (ii)(iii) 得 `0.027·(>f) < q ≤ 1`。∎

**定理 2（单调性）**
(a) `∂r/∂σ = w_σ > 0` 且 `m > 0`，故 `∂q/∂σ = w_σ m > 0`；
同理 `∂q/∂(i/10) = w_i m > 0`，`∂q/∂μ = w_μ m > 0`。
(b) `∂δ/∂Δ = 0.5^(Δ/h) ln(0.5) / h < 0`（`h > 0`），故 `∂m/∂Δ = (1−f) ∂δ/∂Δ < 0`（`f < 1`），
于是 `∂q/∂Δ = r (1−f) ∂δ/∂Δ < 0`（`r > 0`）。
(c) `∂δ/∂h = 0.5^(Δ/h) ln(0.5) (−Δ/h²) > 0`（`Δ > 0`，`ln 0.5 < 0`）。∎

**定理 3（可反转判定）**
`q_B > q_A ⟺ r_B m_B > r_A m_A`。两边同除正数 `r_B m_A`，得 `⟺ r_A/r_B < m_B/m_A`。∎

**推论 1（反转上确界）**
由定理 1(iii)，`m_B ≤ 1` 且 `m_A > f`，故 `m_B/m_A < 1/f`。
于是 `r_A/r_B ≥ 1/f` 时定理 3 右端不成立。
上确界在 `m_B = 1`（`Δ_B = 0`）与 `m_A → f⁺`（`Δ_A → ∞`）时逼近。`f = 0.62` 时 `1/f = 50/31`。∎

**推论 2（不可达）**
取 `m_A = f` 需 `δ(Δ_A) = 0`，即 `Δ_A = ∞`，有限卡龄取不到。
（浮点实现下 `Δ ≈ 10⁹` 天时下溢，`m` 取等于 `f`；实数域上严格大于。）∎

**定理 4（T0 与下限无关）**
`h = 0` 时定义 2 给出 `δ = 1`，定义 3 给出 `m = f + (1−f) = 1`，故 `q = r`，与 `f`、`Δ` 无关。∎

**前五行是输入，后八行全部由输入算出。** 此前的表格省略了 `i` 与 `μ` 两行、只给出乘积
`w_i (i/10)`，读者无从核对——据后续核对，按该表反解得到的 `i` 为 `7` 与 `4`，
而独立的读者计算取 `4` 与 `5`，两者 `r` 不同（`0.839` 对 `0.758`）。
省略输入行是文档缺陷，与算术无关。另外 `μ` 在真实代码中由实体匹配算出，此处作为例题输入给出。

按定理 3：`m_B/m_A = 1.338778 > 1.114706 = r_A/r_B`，故 `q_B > q_A`，B 胜出（余量 `0.224072`）。

**临界 floor。** 对这对候选解 `m_B/m_A = r_A/r_B`，其中 `m = δ + (1−δ) f`：

```
m_A = 0.280616 + 0.719384 f          m_B = 0.928425 + 0.071575 f

(0.928425 + 0.071575 f) / (0.280616 + 0.719384 f) = 1.114706

⇒  f* = 0.842939
```

即 **floor 超过 `0.842939` 时这对候选的次序才反转**；采纳值 `0.62` 与原默认值 `0.70`
都在其下，两者都判 B 胜出。

这与修订前的例题不同：旧版输入（`i = 7` 与 `4`）对应 `r_A/r_B = 1.284839`，
落在 `(1.247828, 1.338778)` 之间，因此在 `f = 0.70` 时会反转。改用本组输入后该反转不再出现。
**`f*` 比「试一个 `0.70` 看是否反转」更精确：它给出的是这对候选的翻转点。**
