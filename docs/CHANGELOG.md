## 2 每版到底改了什么（只写版本级变化）

### v1.2.2（当前）

- **修复**：`tools/moon_cli.py`（插件桥接）原先用系统编码读 stdin，中文 JSON 必崩
  （`UnicodeEncodeError: '\udca2' ... surrogates not allowed`）；改为按 UTF-8 字节读，stdout 一并强制 UTF-8。
- **修复**：`compress.build_summary` 的关键字段回填没有上限，长消息会把 summary 撑到 `4652` 字，
  撞穿 `schema.json` 的 `maxLength: 500` → 整次抽取抛 `SchemaError`。现为 `SUMMARY_MAX_CHARS = 500`。
- **修复**：`next_tier` 把 `T9` 的降级算成了 `T8`（方向反了）。现在方向与落点各只有一处定义
  （`scoring.next_step` + `scoring.stepped_tier`），越界**抛错而不是夹逼**；并加了 10×3 真值表与逐层落点表。
- **行为变更（唯一一处，必须知道）**：`T1` 从「免疫规则升降」改为「**可降**」。
  半衰期 365 天，需闲置 `>730` 天才触发，实际几乎不发生。
  理由：`T0` 与 `T1` 同属常驻区、不受配额（`recall._section_for`），若 T1 只增不减会把预算吃光。
- **撤回**：`W1`「压缩」这条宣称，见 [`withdrawn/W1-compression.md`](withdrawn/W1-compression.md)。
- **不变**：定值、两段门、用例集、装箱规则、全部评测读数。

### v1.2.1

- 召回编排器落地：`recall.py` 串起「定性硬门 → 打分 → 定量硬门 → 装箱」，
  并断言两段合取恒等于 `select()` 的结果；召回保持零副作用。

### v1.2.0

- 定值落地：`TIME_FLOOR = 0.5925`、`THETA = THETA_HIGH = 0.3941`、默认乘性固定下限。
- 评测集契约化：切分按种子冻结，`run_split_integrity.py` 用 SHA-256 校验留出集未被改动。
- 按 R1 新增 3 条边界用例（`23`/`24`/`25`），`run_batch_audit.py` 的 R1/R2 首次通过。

## 4 纪律

1. **一条宣称被撤回，不在别的文档里改口**：其它地方只写「已撤回，见 W1」。
2. **撤回不等于全盘失败**：只撤回那一句话，同版本的其它结论各自有复算命令，照旧成立。
3. **被撤回的记录永不删除**：它是「当时为什么那样想、后来为什么不算了」的证据。
4. 加一个版本 = 加一行表 + 一节「改了什么」，并让 `__version__` 与本表最新行一致
   （`tests/test_docs.py` 会检查这一点）。
