## 🔴 已知问题（Known Issues）

1. **压缩率未达标（`0.7359x`；判据要求压缩组 `T3–T7` `≥ 2.0x`，见 §4.1.1）**：
   原因在于 LLM 对跨消息的信息项未做合并（缺少跨批注册表），以及 `summary` 与四个句子字段存在语义重复。
   实测支撑：`1,058` 条逐句字段里 `77.6%` 已是抽象、复述整句只占 `22.4%`，但颗粒度没降
   （`2.23` 条字段/消息）——**抽象发生了，压缩没有**。
2. **`todos` 硬要点遗漏率 `35.7%`（`25/70`）**：短文本层级的硬字段在生成摘要时容易丢失。
   C8 违规共 `54` 条 = 硬要点漏 `42` + 长度条款 `12`。第 6 条是**否决项**（优先级 `6 > 5`）：
   要点没保住时，压缩率一律不计通过。
3. **`claims` 字段降级（本版实测已消失，备查）**：全量一轮降级 **`0` 次**（旧提示词下 `16` 次）；
   新版提示词给出对象示例后不再出现。保留记录是因为它一度是「形状问题」的代表。
4. **格式滑落（解析层已归一/降级并计数）**：裸数字 `tier` `29` 张（跨 `14` 条用例）、
   非数字 `confidence` `1` 张、markdown 围栏 `1` 批。第一遍跑因此丢过 `14` 条用例的**整批卡**——
   教训是「格式没归一，代价是整批数据」。
